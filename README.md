## 📌 Sobre el proyecto

TempTrack es una solución tecnológica de monitoreo inteligente de temperatura que permite supervisar equipos de refrigeración y conservación de productos sensibles.

Integra dispositivos IoT con sensores físicos, una plataforma web y una aplicación móvil para registrar mediciones, detectar desvíos, generar alertas y consultar el historial de temperatura.

Está orientado a farmacias, restaurantes, laboratorios y otros establecimientos que necesitan mantener un control adecuado de sus equipos y prevenir pérdidas.

## ⚙️ Funcionalidades

- Monitoreo continuo de temperatura.
- Visualización del estado de los equipos.
- Detección de desvíos y generación de alertas.
- Consulta del historial de mediciones.
- Exportación de informes en PDF y CSV.
- Gestión de usuarios, organizaciones y equipos.

## 🛠️ Tecnologías

- **Hardware:** ESP32 y sensor DS18B20.
- **Frontend:** Next.js y TypeScript.
- **Aplicación móvil:** React Native y Expo.
- **Backend:** Supabase y Edge Functions.
- **Base de datos:** PostgreSQL.

## 🚀 Getting Started

Para ejecutar el proyecto localmente:

Primero, instalá las dependencias:

```bash
npm install
```

Luego, iniciá el servidor de desarrollo:

```bash
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en tu navegador.

Podés comenzar a modificar la aplicación editando el archivo `app/page.tsx`.

**Nota:** configurá las variables de entorno necesarias para conectar el proyecto con Supabase antes de ejecutarlo.
